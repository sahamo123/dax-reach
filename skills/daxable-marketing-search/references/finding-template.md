# Finding Format

Use only fields relevant to the task; a copy edit does not need a full audit report.

| Field | Record |
|---|---|
| Finding | Concrete observed behavior or gap |
| Evidence | URL/file, date, tool/method, relevant excerpt or result |
| Status | Observed, user-provided, inferred, or unverified |
| Scope | Local file, rendered page, sampled routes, or measured production data |
| Impact | Visitor/business consequence and confidence |
| Recommendation | Smallest useful fix; official source ID when applicable |
| Verification | What demonstrates the fix and what it cannot prove |
| Priority | Impact, confidence, effort; explicitly editorial judgment |

Conclude with completed changes, checks, and unresolved questions that materially affect the work. Do not invent scores to fill a report template.
