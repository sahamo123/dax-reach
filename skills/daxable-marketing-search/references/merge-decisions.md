# Merge Decisions

The active skill is a curated derivative, not a concatenation or a complete redistribution of both runnable toolkits. Immutable selected files at pinned commits remain in the repository's upstream directory for attribution and comparison. They are not installed, and their relative dependencies are intentionally not vendored. The active workflows are self-contained.

| Input | Retained | Changed or excluded | Reason |
|---|---|---|---|
| Corey product-marketing | Audience, offer, objections, voice, proof, lessons | No mandatory new context file or repeated permission gate | Respect existing context and authorization |
| Corey content-strategy | Intent, original contribution, buyer-stage planning | No mandatory publishing volume or fixed content calendar | Audience need and available evidence govern scope |
| Corey copywriting | Scope diagnosis, clear benefits, factual claims, editing | No inherited example statistics in client copy | Examples are not client evidence |
| Corey CRO | Value proposition, CTA hierarchy, proof, friction, tests | No promised uplift from suggested changes | Mechanisms are hypotheses until measured |
| Corey AI SEO | Brand accuracy, citations, prompt observations | No universal engine preferences inferred from dated studies | Separate Google facts from platform-specific experiments |
| Agrici technical SEO | Crawl/index/render/mobile/metadata checks | No bundled Claude runtime, paid MCP requirements, or automatic hooks | Portable host/tool selection |
| Agrici content | Expertise, usefulness, sourcing, quality review | Remove homepage/service/article word-count floors and link quotas | Google publishes no preferred word count; clarity matters |
| Agrici schema | Existing markup inspection, accuracy, validation | No blanket need to add every type or promise rich results | Feature eligibility is distinct from vocabulary validity |
| Agrici GEO | Access checks, platform distinctions, evidence-backed observations | No mandatory 0–100 GEO score or fixed passage length | Unmeasured scores create false precision |
| Google official guidance | Dated source-backed constraints | No Google-branded endorsement or applicability to every AI engine | Clear authority and platform boundaries |

Google's no-word-count guidance resolves the upstream content-floor tension. Its AI guide resolves special-file and chunk-size claims. Its current update log resolves obsolete FAQ enhancement advice. Its dedicated Search Console documentation resolves the older aggregate-only reporting description. See [Google guidance](google-guidance.md).

This version does not merge upstream crawlers, screenshots, PDF reporting, plugins, paid integrations, or autonomous agents. Use existing host tools when available. Expanding those capabilities requires a concrete use case, security review, tests, and source attribution.
